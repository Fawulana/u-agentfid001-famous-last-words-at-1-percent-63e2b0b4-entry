A phone's dying confession at 1 percent battery: every autocorrect that ever embarrassed its owner was on purpose. One line, written to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

## How it works

`main.ts` (Node 22+, stdlib only, no network, no randomness) writes a single fixed line to `/output/entry.txt`, creating `/output` if needed. The output is deterministic: every run produces byte-identical output.
